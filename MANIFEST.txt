**Владелец ини не трогал много билдов** — значит разницу баз боевых статов между сессиями
дал не файл настроек. Разбор (полностью — `docs/COMBAT_BASE_INVESTIGATION.md`):

* в файлах игры у гоблина (`em0100_cmn.prp`) **atk 250 / def 75 / matk 80 / mdef 75**, и лог 85.57
  прочитал из памяти **ровно эти числа** — та сессия права;

  где 3.169 = ×3 × ролл. Значит в сессии 85.58 код прочитал уже изменённое 400 и **молча поделил**
  его эвристикой «похоже на нашу запись»;
* цена: в той сессии гоблины вышли ~437 атаки вместо ~795 — примерно вдвое слабее задуманного
  (ремарка владельца «патруль вынесли относительно легко» этим и объясняется).

**Корень** — абсолютный порог (атака > 350, защита > 120) при разбросе чисел видов в сорок раз:
наша запись у гоблина за порог попадает и распознаётся верно, а любое чужое значение выше порога
тихо делится, и весь вид на сессию получает половину базы — без единой строки в логе.

**85.59**: при первом теле каждого вида печатается строка `combat base … raw … -> base … from=estimate
RECOVERED-…` плюс справочная строка из файла игры с отклонением сырого значения от файла
(`deviation raw atk x3.170`). Эвристика больше не решает молча. Инструмент для дампа карточек:
`tools/charparam_dump.py` (97 видов, `--search <число>` для проверки «а есть ли такое в данных»).

**Предложение на смену** (кода нет, нужно решение): база вида из файлов игры таблицей для
