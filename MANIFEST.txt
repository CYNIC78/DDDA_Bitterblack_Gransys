**Build 85.60-file-base** — БАЗА БОЕВЫХ СТАТОВ БЕРЁТСЯ ИЗ ФАЙЛОВ ИГРЫ (РЕШЕНИЕ ВЛАДЕЛЬЦА).

«Можно брать базу из файлов игры и множить их. Так надёжно» — так и сделано. Гадания в этом
месте больше нет: `src/runtime/EnemyFileBase.h` — таблица на 91 вид, **сгенерированная** из
`enemies.zip` (charparam/em/*_cmn.prp, смещения 0x0C64/0x0C6C/0x0C74/0x0C7C) командой
`python3 tools/charparam_dump.py --codegen`. Умножение (`attackMult` и прочее) работает как
работало — изменился только источник базы.

**Почему это лечит.** Старый код угадывал базу по абсолютному порогу («выше 350 — значит наша
прошлая запись, делим»), а числа видов различаются в сорок раз: однажды это поделило уже
изменённое значение и вид получил вдвое слабые статы (85.58, гоблин 126.2 вместо 250). Теперь
база — из данных, а два аварийных пути (таблица видов из памяти, затем оценка) остались только
для видов, которых в таблице нет или у которых в файле стоят не боевые числа.

**Отсев.** Годными считаются базы, где все четыре поля > 0 и < 9000. Так отсеиваются нули
(em1200/em1201/em6003) и «иммунные» круглые маркеры (em5100 mdef 10000, em5101 def 10000/
mdef 20000), но сохраняются настоящие крупные бойцы: у em7001 атака 8500 — реальная.

**Лог (по две строки на вид за сессию):**
```
combat base uEm0100 raw atk 400.0 ... -> base 250.0/75.0/80.0/75.0  from=FILE
combat base uEm0100 source=FILE file atk 250.0 def 75.0 matk 80.0 mdef 75.0
```
Плюс строка `RAW MISMATCH` только если прочитанное из памяти расходится с файлом больше чем на 3%
— в норме её нет.

**Фикстура `filebase_test`** (в гейте): числа гоблина совпадают с полем (250/75/80/75), хоб 410,
волк 220, харпия 350, крупный em7001 не отсеян, нули и иммунные маркеры отсеяны, дублей emId нет.
Заодно выяснилось: часть карточек лежит в нескольких папках (em5401_cmn.prp есть и в em5401/,
и в em5402/) — генератор их дедуплицирует по номеру вида.

**Ожидаемый эффект в поле:** гоблины вернутся к задуманной крепости — в прошлой сессии база была
занижена вдвое, теперь она 250, и при ×3 атака солдата выходит ~866 вместо ~437. Если покажется
много — это ручки `attackMult`/`defenseMult` в живом `ddda_entities.ini`.
