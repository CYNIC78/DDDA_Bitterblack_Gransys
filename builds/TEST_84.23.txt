84.23-on-field — что проверить дома
===================================

Сборка
------
Visual Studio → Release | Win32 → Build Solution.
(в первом паке 84.23 падали EntityConfig/EnemyTuner: leftover
`extern std::ofstream logFile` против LogMem ostream — снято.)
В папку игры: Release\dinput8.dll + ddda_ai_overhaul.ini
(старый dinput8.dll убрать/переименовать).

Первая строка лога (после ВЫХОДА из игры):
  ... build 84.23-on-field ...

Пока игра открыта, файла ddda_ai_overhaul.log быть не должно.
Он появляется при нормальном выходе или при краше.

Тест A — соло / Разлом (главное в 84.23)
----------------------------------------
Главную пешку оставить в Разломе (обрыв / таймер воскрешения истёк /
камень не трогали). Играть дальше.

Ожидаем:
  * нет policy FAIL-CLOSED identity-MainPawn-body-unresolved-or-duplicate;
  * нет бесконечного «party composition changed - rescanning»;
  * после трёх промахов ОДНА строка:
      PartyRecon: records show N pawns, the body scan finds M - treating missing as rifted
    и скан кучи каждые 20 с больше не идёт;
  * нет спама PartyPositions: pawn read FAILED pawnIdx=-1;
  * бой Аризена (+ кто ещё на поле) идёт; rifted-пешка не становится PackMark.

Временный соло (пешка пала, не успели поднять) — тот же контракт.
Downed на земле — не рифт: тело есть, слот остаётся в охоте.

Тест B — загрузка сейва (барьер 84.22 жив)
------------------------------------------
Один сейв: загрузить → титул → загрузить, раз 8–10.
Director [monsterAI] wolfActuator = off.
Ищем краш на load. В логе:
  WorldScan: FAIL-CLOSED world-unload
ровно по числу уходов в титул/загрузку.

Тест C — полная партия, как раньше
----------------------------------
Три пешки на поле. Гоблины / волки. Поведение 84.21/84.22 не должно
«поплыть». Вернуть пешку из Разлома камнем — партия снова полная,
identity не орёт.

Не обещаем
----------
Краш на пляже после зачистки (1 из ~10): InWorld() остаётся true.
P0-2 / P0-3 открыты. Если повторится — пришлите лог.

Не трогать в этом билде
-----------------------
Nightmare, арена, охота Possession, запись DDDA.sav.
wolfActuator лучше off на тесте B.
