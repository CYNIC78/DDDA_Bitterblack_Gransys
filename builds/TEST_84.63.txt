84.63-dpad-order-watch-probe
Исследовательский зонд OrderWatch для захвата ванильных команд D-pad ("Ко мне!" / "Вперед!" / "Помогите!").

Собрать: Release | Win32. Тег: 84.63-dpad-order-watch-probe.
dinput8.dll в папку с DDDA.exe.

Что делает модуль OrderWatch (Read-Only Probe):
1. Неинвазивно отслеживает вход Аризена в состояние `cPlActCMCOrder` (136 байт) при нажатии крестовины D-pad.
2. Снимает точный дамп полей команды:
   - Order type, button ID, payload (dwords).
3. Синхронно опрашивает состояние всех 3 пешек в этот точный момент:
   - Текущий Goal code и цель планировщика (PawnPriorityCode, cAIGoalPlanning);
   - Текущее действие FSM (cPlAct*);
   - Дистанция до Аризена;
   - Загруженные GOAP-интерфейсы.
4. Фиксирует изменения 9 инклинаций в памяти (чтобы замерить, как ванилла пытается сдвинуть веса).

План теста:
1. Зайти в игру с полной партией.
2. Вне боя и в бою нажать по очереди:
   - D-pad Вниз («Ко мне!» / Come!);
   - D-pad Вверх («Вперед!» / Go!);
   - D-pad Влево/Вправо («Помогите!» / Help!).
3. Сделать между нажатиями паузы 3–5 секунд.
4. Выйти из игры и прислать лог:
   - Мы увидим точные байты приказов, реакцию пешек и раскладку целей!
