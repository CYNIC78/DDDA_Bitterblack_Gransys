Build 63 — Guardian: ролевая матрица + аудит под меч/двуручник

Собрать:
  Visual Studio → Release | Win32 → Build Solution

Проверить в F12:
  build 63-guardian-role-matrix

ЧТО СДЕЛАНО (заготовка для Файтер/Варриор)
=========================================

1. РОЛЕВАЯ МАТРИЦА (вокация пешки × вокация Аризена).
   Раньше ответ зависел только от вокации ПЕШКИ. Теперь от пары:

     мили-пешка (Fighter/Warrior/MysticKnight):
       + кастер-игрок (синий)  -> Protector  (телохранитель: держись у кастера,
                                              перехватывай, не давай сблизиться)
       + мили/лучник-игрок    -> Assault    (штурмовая поддержка: бей вместе
                                              с игроком на переднем крае)
     гибрид (Strider/Assassin) -> Adaptive (универсал, БЕЗ разделения)
     дальнобойная пешка        -> RangedHold
     кастер-пешка              -> Support

   Твоя пешка сейчас страйдер -> роль Adaptive (как и было). Разделение
   Protector/Assault включится, когда пешка станет Файтер/Варриор.

2. GUARDIAN-SCOPED АУДИТ (переписан).
   Кнопка «Audit Guardian penalties» теперь сканирует ВСЕ priority-строки и
   находит каждое правило, чей check ссылается на Guardian (id склонности 5).
   Раньше был жёсткий список кодов (4/13/15/54/57/60/66).
   Теперь, когда пешка сменит вокацию на Файтер/Варриор, аудит САМ покажет
   код меча (WpnSwordAtk) / двуручника (WpnGSwordAtk) и их Guardian-штрафы —
   без угадывания. Тогда подключим снятие штрафа к этим кодам в совете.

ЧТО ПРОВЕРИТЬ (read-only, ничего не пишет)
==========================================

1. Компилируется ли.

2. Панель Guardian Doctrine: строка «Role: Adaptive» (страйдер, как и было).

3. Нажми «Audit Guardian penalties» — в логе теперь блок:
     GuardianAudit code=54 ... (кинжалы, как раньше)
   + подробно «rule[N] AddS32=... checks=[incl5/rank2,...]».
   Статус покажет «N rows with Guardian rules».

ЧТО ПРИСЛАТЬ
============

1. Компилируется ли.

2. Строку «Role: ...» из панели.

3. Из лога блок GuardianAudit (с новым форматом checks=[incl..]).
   Важно: должен по-прежнему показывать code 54 с его правилами — это
   подтверждает, что аудит ничего не сломал.

ЗАГОТОВКА НА БУДУЩЕЕ (после города)
====================================

Когда пешка станет Файтер/Варриор:
  - роль сменится на Protector (ты кастер) или Assault;
  - нажми аудит -> увидишь код меча/двуручника + штрафы;
  - пришли мне -> добавлю снятие штрафа для этого кода в совет (как сделали
    с кинжалами code 54).
