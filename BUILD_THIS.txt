Build 39 — Player/Main Pawn live trace (read-only, safe hotkeys)

Собрать:
  Visual Studio → Release | Win32 → Build Solution

Проверить в F12:
  build 39-party-live-trace-hotkeys

Настройки:
  [devtools] enabled = on
  [pawnAI]   enabled = on

Перед тестом:
  1. Оставить только главную пешку.
  2. Загрузиться вне Рифта/города, рядом со слабым противником.
  3. Тест ничего не пишет в память персонажей.

Запуск:
  1. F12 → DevTools → Player + Main Pawn recon.
  2. Нажать "Find both + start live trace" один раз.
  3. Дождаться двух строк: Arisen uPlayer и Main Pawn uCmc.
  4. Закрыть F12. CSV уже записывается автоматически.

Короткий тест ГГ:
  1. Стоять 3 секунды.
  2. Бежать БЕЗ спринта 3 секунды.
  3. Спринтовать 4–5 секунд, чтобы заметно потратить stamina.
  4. Остановиться на 5 секунд (stamina восстанавливается).
  5. Позволить слабому врагу ОДИН раз ударить ГГ.
  6. Отойти и спокойно постоять 3 секунды.
  7. Нажать клавишу - один раз — это остановит и закроет CSV.

Важно:
  - Используются физические клавиши - и = рядом с Backspace.
  - Клавиша - включает/выключает live trace.
  - Клавиша = делает резервный snapshot; в этом тесте нажимать её НЕ НУЖНО.
  - F9/F10 инструмент больше не использует.
  - Пешку заставлять спринтовать НЕ НУЖНО.
  - Если враг ударить не смог, всё равно завершить клавишей - и прислать результат.

Прислать из DDDA_AI_Overhaul:
  ddda_party_live_001.csv
  ddda_party_recon_001.json
  ddda_ai_overhaul.log

Контрольные значения исходного сейва:
  ГГ: HP 331/498, stamina 600
  Главная пешка: HP 327/505, stamina 595

Что проверяет Build 39:
  - повторяемость Wait/Run/Dash и кандидатов raw enum/flag;
  - 128-байтные окна pBase-записей игрока и пешки;
  - живые DTI-объекты с именами Stamina/Health/Status;
  - изменение HP и stamina во времени без exact-value scan тела.
