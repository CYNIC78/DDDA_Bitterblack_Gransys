# STQ_FORMAT — бинарная раскладка .stq (STRQ), музыкальная очередь DDDA

Статус: **CONFIRMED (оффлайн, R0)** — вскрыто якорным методом на двух
независимых файлах (`bgm.stq`, `Tittle_bgm.stq`), три поля подтверждены
совпадением с известными значениями оригинального титл-трека.
Парсер: `tools/stq_dump.py`. Карта треков: `docs/generated/BGM_MAP.md`.

## Контейнер

```text
+0x00  4s   magic "STRQ"
+0x04  u32  версия = 27 (0x1B)
+0x08  u32  число записей главной таблицы (2 / 125)
+0x0C  u32  назначение невыяснено (5 / 171)
+0x10  16B  нули (reserved)
+0x20  u32  смещение главной таблицы = 0x3C
+0x24  u32  смещение второй таблицы = 0x3C + count*24
+0x28  u32  -1 (sentinel)
+0x2C  u32×5  пять раз указатель на начало строкового блоба
```

## Запись главной таблицы (24 байта), с 0x3C

| Смещение | Тип | Поле | Подтверждение |
|---:|---|---|---|
| +0x00 | u32 | абс. смещение имени (`bgm\wave\No_001`, без расширения) | строки в блобе |
| +0x04 | u32 | **размер файла, байты** | якорь: `0x00514ACE` = 5 327 566 ✓ |
| +0x08 | u32 | **всего сэмплов** (длительность = value/48000) | титл: 87,5 c = 1:27 ✓ |
| +0x0C | u32 | **каналы** (1 / 2 / 6) | титл 6ch ✓ |
| +0x10 | u32 | **луп-старт, сэмплы** (−1 = одноразовый) | Zako_1/2/3: ровно 5,000 c |
| +0x14 | u32 | **луп-энд, сэмплы** (−1 = одноразовый) | Zako_1/2/3: ровно 107,000 c |

Семантика лупов: `[+0x08]` > `loopOut` → хвост за лупом (титл: 87,5 c при
лупе 57,0→85,0 c). 63 из 125 записей — одноразовые (−1/−1).

## Вторая таблица (по +0x24), запись 24 байта, то же число записей

Наблюдения (титл): флаги 0/1, громкость 0..127, float-пары −3.0 / −96.0
(похоже на dB: единичный фейд и «пол» тишины), константа 100.
Назначение: параметры воспроизведения. **Для MVP-патча не требуется.**

## Что патчим под подмену (runtime, после R1/R2)

- `+0x04` size — всегда (иначе краш, подтверждено пользователем);
- `+0x08` samples — под новый трек (луп-окно и длительность);
- `+0x0C` channels — только если позволим нестандарт (спек: каналы = оригиналу);
- `+0x10/+0x14` — политика под новый трек: пересчёт пропорционально
  или «луп на весь файл минус хвост». Решается на R2 A/B.
