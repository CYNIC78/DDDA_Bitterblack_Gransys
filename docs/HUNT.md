## Перенос (волк → гоблин, Drenched → Possession)

```text
якорь из SoT
  → DUMP / CARDRECON / snapshot to log
  → кадр A (до события) + кадр B (сразу после)
  → дифф внутри якоря (±32 B или одна карта)
  → в SoT / FIELD_MAP только после двух независимых A/B
```

Событие должно быть **ванильным и одним**: удар, вода, grab, revive.
Не «походить вокруг и снять census».

## Чего не вскрываем

Полный атлас `uPlayer`/`uCmc`/`uEm*` (23–30 КБ × 35 видов) — **не цель**.
Вскрываем только поле, без которого ломается конкретная фича из SoT §13.

Не охотимся «на всякий случай»:

- универсальный HP всех `uEm*` (нет политики, которая его ест);
- planner/priority монстров (Director — не native AI);
- hitbox / урон / stagger;
- человеческие враги (`uHumanEnemy`);
- остальные 33 вида без строки в `SpeciesCard`;
- каждый child в 4405 типах TypeAtlas.

Цена полного вскрытия — месяцы живых сессий, продукт от этого не двигается.
