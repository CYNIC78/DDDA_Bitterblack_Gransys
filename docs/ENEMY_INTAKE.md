# Приёмка врага — один замер, без туризма

Не 98 боёв. Не «пройти игру». Семья закрывается один раз.

## Одна кнопка (бой)

`F12` → **Enemy AI Overhaul** → прокрутить до
`Monster director (Build 012 urgency + mobilization)` → **`snapshot to log`**.

Выйти из игры (лог пишется на выход). Прислать `ddda_ai_overhaul*.log`.

Не Type Atlas DUMP. Не Aggro `snapshot`. Не `=`. F9 не трогать.

## Что заполняется из лога

| Куда | Автоматом? |
|---|---|
| Наклейка в `BestiaryData.h` (кто это) | да, если DTI + акт + Флаффи сошлись |
| Семья / архив `emXXXX.arc` | да, стол + лог |
| `SpeciesCard` / Tempo / Director **запись** | **нет**, кроме уже допущенных: волк, гоблин, хобгоблин, **сауриан 84.29** |

Новый вид в логе ≠ новый rage-профиль.

## Что не надо снимать

Разновидности одной семьи (скелет / рыцарь / лорд, обычный / серный ящер)
делят `cEm*` и один архивный корень. Один живой представитель закрывает семью.

Стол (98 `.arc` + TypeAtlas + Флаффи) закрывает подпись **без боя**.
Бой нужен, только если стол спорит сам с собой, или мы собираемся **писать** в этот вид.

## Стол

```text
dir /b nativePC\rom\enemy\*.arc
```

Один список — не распаковка 98 архивов.

Дальше: `python3 tools/enemy_intake.py` и при наличии лога
`python3 tools/enemy_intake.py --log путь.log`.
