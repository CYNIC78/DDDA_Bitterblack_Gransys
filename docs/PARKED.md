# PARKED — что выключено намеренно

**Зачем этот файл.** Проект большой, и в нём много выключенного. Часть —
сознательная парковка («пока не надо», «не всё найдено», «заморожено до лучшего
решения»), часть — настоящая поломка. Снаружи они выглядят одинаково, и это
дорого стоит: сеанс, который не может отличить одно от другого, приносит
владельцу его же дизайн-решения как «находки».

Этот файл — единственное место, где сказано, что выключено **по решению**.

**Правило пользования:**

```text
выключено и есть в этом файле        → так задумано. Не «чинить», не предлагать включить.
выключено и НЕТ в этом файле         → либо поломка (§«Не парковка»), либо вопрос к владельцу.
включить и посмотреть, что получится → можно, если это не мешает текущему тесту.
```

**Владелец проекта в UI не ходит.** Он закидывает в игру только `dinput8.dll`.
Просьба «включи галку, посмотри» = просьба потратить его время. Поэтому у каждой
записи есть цена включения, и она честная.

## 3. Открытые вопросы к владельцу

1. **`ddda_entities.ini` — особый риск.** Автодописывание ключей там выключено
   *намеренно* (трёхуровневое наследование `default → class.* → emXXXX` ломается
   при backfill). Значит ручные `attackMult` / `defenseMult` восстановить неоткуда.
2. **Nightmare по умолчанию** — публичный дефолт не выбран. Три варианта разобраны
   в `RELEASE_CHECKLIST.md` §2.1, решение там же помечено как **не закрытое**.
3. **MonsterCards** — доводить интеграцию или это задел?
4. **Пороги `guardianMinRank` / `guardianMinIncl`** — общие с Nexus, но названы
   по одному потребителю. Меняя порог гвардиана, меняешь и Nexus.
5. **Рабочий ини** — удалять из git нельзя (владелец диктует правки, источник
   подсказок — `git diff`). Нужен узкий фикс: оставить в git, исключить из зипа.

## Как добавить сюда запись

Если что-то отключается **осознанно** — оно обязано попасть в §1, с причиной и
ценой включения. Причина пишется как решение, а не как состояние:

```text
плохо:  "модуль выключен"
хорошо:  "выключен, потому что поиск таблиц занимает 2+ с, в бою недопустимо;
          быстрее не нашли, поэтому сделан внешний инструмент"
```

Без причины следующая сессия примет парковку за недоделку и предложит её «починить».
