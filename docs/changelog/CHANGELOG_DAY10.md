# День 10 — 17.08.2026: Build 58 — градиентная зона телохранителя

## Контекст

- Подтверждено (Build 57.3): distance-aware фикс работает, пешка бьёт кинжалами
  в ближнем радиусе при Guardian в потолок.
- Идея пользователя: «зона телохранителя» — кастомный радиус, где враг
  «потенциально опасен», пешка заранее готовится. Плюс жалоба на weapon-switch
  истерику из-за быстрых волков.

## Решение

- Лук (code 57) personality=0 — прямой штраф невозможен без структурной записи.
- Вместо этого — ГРАДИЕНТ на кинжалы (code 54 rule 0), который переигрывает лук:
    вне зоны  → -3 (vanilla)
    preempt   → 0  (снять штраф, «готовность»)
    melee     → +2 (бонус, фиксация на перехвате)
- GuardianFixSetTarget(int32_t) вместо SetArmed(bool); tick поддерживает
  плавную смену desired (write+readback+откат при неудаче).
- Новые ini-ключи: guardianPreemptRadius, guardianDaggerBiasMelee,
  guardianDaggerBiasPreempt.
