# День 11 — 17.08.2026: Build 59 — разведка target-selection слоя

## Контекст

- Build 58 (градиентная зона телохранителя) зафиксирован как milestone.
- Наблюдение пользователя: пешка бьёт «не туда» (цель выбирается штатным

## Что сделано

- Отдельная коллекция `g_targetSel[]` в census: объекты target-selection
  (sRecognition/sRecognition::cEnemyInfo, sLockOnManager/*, sUnitSearchManager,
  cTarget*), которые раньше отсекались `PawnAiRelevantName`.
- `DevTools::TargetSelectionAudit()` (read-only): дамп в лог + корреляция
  ссылок на тела врагов + отметка (CURTARGET) по uCmc+0x2EB8.
- Кнопка «Audit target selection» в панели Guardian Doctrine.

## Цель

По нескольким снимкам с разными целями найти поле threat-скора в cEnemyInfo,
чтобы затем точечно (A/B) дать бонус врагам в радиусе Аризена — пешка начнёт
выбирать релевантные цели (того, кто угрожает игроку).
