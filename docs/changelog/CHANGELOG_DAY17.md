# День 17 — 18.08.2026: Party Cam (режиссёрская камера) — фича закрыта

## Что сделано (Build 68.x)

Новый режим камеры **Party Cam** (ранее Pawn Cam):
- хоткей NumPad 1 (`camera_keys.pawnCam`, по умолч. 0x61);
- камера позиционируется blend(Аризен, пешка, bias) + высота + плавность;
- **Bias** (0..1): 0=у Аризена, 0.5=посередине (кинематографичный «вид со стороны»),
  1=у пешки — динамическая позиция в зависимости от взаимного расположения ГГ и пешки;
- взгляд — игрока, позиция — камеры (не «от первого лица» пешки);
- smoothness захАрдкожен на 0.01 (только там нет гостинга).

## Технические выводы (важно для будущего)

1. **Гостинг = борьба двух писателей за current-позицию камеры** (+0x10):
   наш lerp vs штатная интерполяция игры. На lerp=0.01 борьба невидима.
2. Запись в «target» (+0x60) НЕ работает: current не едет к нему (интерполяцию
   ведёт другой потребитель). Кандидаты target-полей: +0x60/+0x0A0/+0x0E0 (дамп 68.3).
3. Настоящий target — отдельная RE-задача (в техдолг).
