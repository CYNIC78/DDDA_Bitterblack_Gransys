## Build 57.3 — distance-aware фикс

- Расшифрована семантика checks (SOURCE_OF_TRUTH §3.5.2): `+0x04` = 0-based
  inclination id (совпадает с InclIdx), `+0x08` = ранг (2=primary, 1=secondary,
  0=tertiary). Агрессивные → бонус, оборонительные → штраф.
- Лук code 57 = personality 0 (SOURCE_OF_TRUTH §3.5.3) — нет штрафов. Это
  объяснило «кинжалы → лук» из теста 57.1: на дистанции лук честный выбор.
- Фикс distance-aware: снятие -3 только при угрозе в guardianMeleeRadius (6 м).
