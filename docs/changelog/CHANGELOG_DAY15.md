# День 15 — 18.08.2026: Build 63 — ролевая матрица Guardian + аудит под меч

## Контекст

Пользователь: заготовка под Файтер/Варриор. Мили-пешки должны быть:
- активными защитниками кастера-игрока (синий);
- штурмовой поддержкой мили/лучника-игрока (красный/жёлтый).
Страйдер (гибрид) — без разделения (универсал).

## Что сделано

### Ролевая матрица (GuardianDoctrine)
- `GuardianRole` enum + `GuardianRoleName` + `GuardianRoleOf(pawn, anchor)`.
- `Decide()` теперь ставит роль по паре вокаций (было — только по пешке):
  melee+кастер → Protector, melee+мили/лучник → Assault, hybrid → Adaptive,
  ranged → RangedHold, caster → Support.
- Совет (reason) помечен ролью. UI показывает «Role: ...».

### Guardian-scoped аудит (DevTools)
- `GuardianPenaltyAudit()` переписан: сканирует ВСЕ priority-строки и находит
  каждое правило с check на Guardian (incl id 5), вместо жёсткого списка кодов.
- Автоматически вскроет код меча (WpnSwordAtk) / двуручника (WpnGSwordAtk),
  когда пешка станет Fighter/Warrior — без угадывания.
