# Роадмап — живая нервная система, не пак .arc

**Версия:** 13.08.2026 (день 4: dump22 паспорт uEm8000; zip 29 ресид пустого списка). Старый роадмап из README / RESEARCH / EnemyAI.cpp — архив.
**Правило дома:** умеем в рантайме — делаем в рантайме. На диск лезем только когда движок физически не может. И даже тогда диск не решает. Решает живой модуль.

---

## 1. Кто мы

Идея с CE не изменилась. Изменилось только то, сколько рычагов мы уже держим.

Мы делаем **эмерджентный рантайм-мод**: мир и пешки ведут себя иначе, потому что мы *видим* живое состояние и *пишем* в него каждый тик. Инклинации плывут. Utilitarian дышит знанием. Прессет сам меняется о категорию врага. Это не пресет-пак и не World Difficulty 2.

Lefein правила мёртвые файлы — и это было сильно для 2010-х. Мы живём в процессе. Уникальность не в том, что мы тоже умеем ARCtool. Уникальность в том, что `.arc` для нас — библиотека, а не игра.

Метафора, которая совпадает с руками:

```
TypeAtlas + FieldMap + WorldScan     = глаза  (бедный REFramework)
CombatBus                            = нервы
PawnAI / Nightmare / EnemyAI / …     = органы
DevConsole                           = стол хирурга, не товар для игрока
.arc / LOT / XML                     = аптека. Препарат выдаёт врач, не аптекарь.
```

Модули остаются сырыми и съёмными. Кривой Nightmare не роняет SmartUtil, потому что оба только слушают шину. Это уже есть. Так и оставляем.

## 2. Три полки. Это и есть наша мапа

Каждая будущая фича сначала кладётся на полку. Не «в какую фазу», а **куда ей можно**.

| Полка | Что это | Пример уже у нас |
|---|---|---|
| **LIVE** | Читаем/пишем процесс. Эмерджентно, обратимо, без рестарта | инклинации, mStudyFlag, хук урона, погода `+0xB8780`, пауза, камера |
| **CATALOG** | Мёртвые таблицы, которые LIVE *читает как политику* | `types.tsv` → TypeAtlas, `bestiary.py` → BestiaryData, таблица Goblin→Greater Goblin |
| **PACK** | Файлы, без которых движок *не умеет инстанциировать* объект | `em7002.arc` в зоне, где его нет; расширение `.gpl`; доп. LOT на Деймона в Грансисе |
| **MEMORY** | Наша запись мира на диск. Не ini, не `DDDA.sav` | давление на лагерь, исход энкаунтера, состояние Nightmare, мутации спавна |

### Полка MEMORY — мир не обязан забывать

Рантайм ≠ амнезия. Процесс умрёт — наши числа могут жить в *нашем* файле.

`ddda_ai_overhaul.ini` — это **настройки игрока** (вкл. модуль, якоря, smooth). Пишется на каждый клик в F12 через `WritePrivateProfile`. Alt+F4 переживает не потому что мы героически флашим в `DllMain`, а потому что ini уже на диске. Туда нельзя класть сотни лагерей и FSM: буфер чтения 1 КБ, нет версий, нет атомарности, смешивается с руками игрока.

MEMORY — отдельный sidecar, например `ddda_ai_overhaul.mem` (или рядом с `DDDA.sav`, с ключом персонажа):

```
prefs  (ini)     что игрок хочет           переживает любой сейв
MEMORY (sidecar) что мир помнит            привязан к персонажу / сейву
DDDA.sav         что помнит Capcom         не трогаем
```

Пишем только то, что *наше*: ключ места, счётчики, состояние маленького FSM, параметры мутации. Не указатели, не живые `uEm*`, не куски `DDDA.sav`.

**Когда флашить.** Не в `DLL_PROCESS_DETACH` (loader lock, поздно, опасно). У нас уже есть `pSave` из Hotkeys — умный момент = хук/соседство с сохранением игры (F5 / чекпоинт / автосейв). Плюс после закрытия энкаунтера. Тогда «я перезагрузил сейв» и «мир забыл этот бой» совпадают. Опция Nightmare: мир не забывает даже после релоада — отдельный флаг, не дефолт.

**Ключ персонажа обязателен.** Один глобальный файл + NG+ = поздняя игра давит на нового Воскресшего. Ключ: имя/уровень/время из `pBase` + путь `DDDA.sav` (mtime/size). Не нашли ключ — не грузим чужую память.

Спавн-FSM из этой полки:

```
энкаунтер кончился → обновить site{clears, pressure, state}
сохранение игры    → атомарно записать MEMORY
следующий спавн    → LIVE-хук emId читает site, мутирует тёплый тип/вес
GPL отказал        → деградация в ваниль, не PACK «на всякий»
```

Состояния держать крошечными (`virgin / hunted / hardened / depleted`), не общий движок FSM. Пока нет ключа *места* (лот / клетка `st100_XXmYYn` / `sSetManager`) — память живёт грубее: по семье врага и стадии. Этого хватит, чтобы идея проверялась до фазы 2.4.

Подробности реализации — когда режем скелет `ModStore`, не раньше фазы 0.4 (сканер должен уметь сказать «энкаунтер кончился»).

### Правило четырёх вопросов

1. Можем **увидеть** это живым? → Atlas / Scan / хук.
2. Можем **изменить** живым? → запись поля / подмена аргумента нативного вызова.
3. Движок **отказывается создать** объект (нет arc, режет GPL, нет navmesh)? → тогда PACK.
4. PACK никогда не включает себя сам. Его включает LIVE-политика. Нет файла — политика деградирует (оставляет ваниль, пишет лог), а не падает.

### Тупо vs умно — на наших же заготовках

| Фича | Тупо (старый роадмап) | Умно (теперь) |
|---|---|---|
| Bitterblack Gransys, ночь/погода | — | LIVE. Уже набросано. Добить оффсет часа и тик. |
| Bitterblack, замена монстров | Подменить `game_main.arc`, рестарт | CATALOG-маппинг + хук чтения emId в `cLayoutSetEnemy`. Ванильный LOT. Политика Nightmare решает *сейчас*. Нет тёплого типа — оставить ваниль. |
| Деймон в Кассардисе | Тоже своп .arc | PACK как *опция*. LIVE решает, грузить ли. Не обещаем в v1. |
| «Враги злее» | Hex FSM / слайдеры в UI, которые ничего не пишут | Найти живой `cThinkMgr` / `cCharParamEnemy`, множить поля. XML Lefein — CATALOG, не замена файлов игрока. |
| AIPlActParam пешки | Распаковать, править XML, запаковать | Снять поля в Generated.h. Найти загруженный объект. Писать веса LIVE. Чужой XML-мод не затираем — мы слой сверху. |
| CombatIntel | Ждать удар | WorldScan: кто в комнате до первого хита. Удар обогащает (кто бил, знание), не *создаёт* мир. |
| TargetLock | CE на yaw, Alt+X | ptr врага со сканера → вектор на него → yaw. |

Статика, которую мы оставляем себе как право, а не как план:

- новый тип в зоне, где его никогда не было (GPL + arc);
- новая постановка, которой нет в LOT (плотность, босс «не там»);
- новый граф состояний FSM, которого нет в ванили (редко, дорого, почти никогда).

Всё остальное — LIVE или CATALOG.

## 4. Что мы сознательно не делаем

Чтобы роадмап снова не распух чужим:

- **Чит-слой dinput8.** Статы ГГ, предметы, год-мод, спавн ради спавна. Консоль может это иметь под `[devtools]` для нас. В F12 игрока — нет.
- **Обещание PlaceAtMe.** Спавн «любого в любой точке» — не продукт. Продукт — политика над *тем, что движок и так ставит*.
- **Замена game_main.arc у игрока** как основной дистрибутив Nightmare. Ломает другие моды, требует рестарт, убивает эмерджентность.
- **Hex всех FSM** «чтобы враги были умнее». Сначала живые поля think. FSM — если не хватит состояний, не если не хватит желания.
- **Вокации/аугменты как чит прокачки.** Как *вход* в AI-политику пешки — можно позже. Как «поставь Magick Archer кнопкой» — нет.

### Фаза 2 — Политика мира. Nightmare как первый настоящий орган

| Срез | Полка | Суть |
|---|---|---|

| 2.3 CATALOG замен | CATALOG | Goblin→Greater Goblin и т.д. из наших реальных TypeId, не из старого `em.txt`. Деградация: нет тёплого кузена → ваниль |
| 2.4 Хук emId | LIVE + MEMORY | в момент постановки подменить тип по политике Nightmare **и** по FSM места (pressure/state из sidecar). Ванильный LOT не трогаем |

### Фаза 3 — Ум врага, тоже живой

EnemyAI.cpp выкидывает сказку «правь XML руками».

| Срез | Полка | Суть |
|---|---|---|
| 3.1 Найти think | LIVE | `cThinkMgr`, `cAIPriorityThink`, `cCharParamEnemy` через Atlas + сканер |
| 3.2 Поля | FieldMap | агрессия, цель, таймеры, флаги. Пишем множители, не «новую душу» |

Критерий: слайдер «aggression» в F12 наконец что-то делает — потому что пишет в живой объект, а не в ini в никуда.

### Фаза 4 — То, чего рантайм физически не может

Не «контент-пак как продукт». Аптека.

- постановка, которой нет в LOT (плотность, встреча);
- тип, который зона никогда не грузила (Деймон не в своей комнате);
- расширение GPL.

Форма: sidecar рядом с DLL или в `nativePC` под нашим именем, не overwrite `game_main.arc`. Включает LIVE-флаг. Выключил Nightmare — игра снова ваниль после перезахода в клетку / рестарта, без ручного «restore arc».

Это дополнение к динамической системе. Не замена.

### Фаза 5 — Открыть каркас

- TypeAtlas + FieldMap как ресурс сообщества (уже начали).
- Шаблон модуля = `SmartUtilitarian` (уже есть).
- Lua не обещаем. Политика = C++ модуль + ini + CATALOG.

## 7. Как добавлять фичу, чтобы роадмап снова не протух

В PR / в чате три строки, не больше:

```
Полка: LIVE / CATALOG / PACK
Почему не полка выше?
Кто подписывается на шину? (или это глаза, тогда Publish)
```

Если ответ «PACK, потому что так Lefein делала» — этого мало. PACK только после «движок отказался создать».

Этот файл — север. README держит пользовательское. RESEARCH — историю реверса. DEVTOOLS_VISION — как устроены глаза. Когда реальность меняется (а она меняется каждые два дня) — правим **этот** файл, не пять копий.
