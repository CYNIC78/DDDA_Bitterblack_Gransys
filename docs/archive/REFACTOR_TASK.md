# Рефакторинг слоёв — выполнено (Build 69)

**Статус: закрыто.** Продуктовый слой вынесен из `DevTools.cpp` в `src/runtime/`
и больше не зависит от исследовательского флага. Документ оставлен как запись
того, что и почему было сделано, плюс список того, что осталось.

Проверка инварианта автоматизирована: `python3 tools/analyze_devtools_layers.py`
падает с кодом 1, если продуктовый код снова заведётся в `DevTools.cpp`.

## 1. Что было сломано

`DevTools.cpp` (7714 строк) смешивал три слоя: продуктовый runtime,
исследовательские пробы и собственно DevTools.

**Баг 1 — продуктовый тик под research-флагом.**

```cpp
void DevTools::WorldScan_Tick() {
    if (!g_enabled) return;   // [devtools] enabled = off ломал продукт
```

**Баг 2 — инициализация под тем же флагом.** `Hooks::DevTools()` при
`enabled = off` выходил до `BuildWatch()` и до загрузки priority-профилей.
То есть у обычного игрока профили не поднимались вообще.

**Баг 3 — пробы в продуктовом UI.** `src/PawnAI.cpp` рисовал в продуктовой
панели пять research-кнопок и через них вызывал research-код.

**Баг 4 — вся инициализация внутри `if (Hooks::InGameUI())`.** Отвал оверлея
молча убивал и продукт.

## 2. Что сделано

### Новая структура

```text
src/runtime/                 продукт, работает ВСЕГДА
  Runtime.h                  публичный API для модулей поведения
  Runtime.{h,cpp}            Init/Shutdown, точка входа продукта
  RuntimeInternal.h          внутренний контракт: типы, состояние, объявления
  RuntimeState.cpp           определения всех разделяемых переменных
  MemProbe.{h,cpp}           фундамент: память, секции образа, DTI-имена
  WorldScan.cpp              обход актёров, враги, публикация WorldReport
  PartyRecon.cpp             uPlayer/uCmc, тела партии, роли, позиции
  PriorityPlatform.cpp       транзакционные профили + Guardian-фикс

src/devtools/DevTools.cpp    ТОЛЬКО исследование: SCAN/DUMP/HUNT/TypeAtlas
```

### Инверсия зависимости

Продукт больше не вызывает research напрямую. Точка расширения ровно одна:

```cpp
struct ResearchHooks {
    void (*onSnapshotEarly)();
    void (*onSnapshotFull)();
    void (*onTick)();
    void (*onWorldUnload)(const char* reason);
};
```

DevTools регистрирует реализацию при инициализации. Панель выключена —
указатели нулевые, продукт просто идёт дальше.

### Порядок старта

```cpp
Runtime::Init();          // продукт: база образа, секции, priority-профили
Hooks::Hotkeys();
if (Hooks::InGameUI()) {  // UI и research — вторым эшелоном
    ...
    Hooks::DevTools();
}
```

Выключение: `Hooks::DevTools_Shutdown()` (research) → `Runtime::Shutdown()`
(откат транзакционных правок).

### Удалено

| Что | Почему |
|---|---|
| `FollowProbe`, `FollowProbeProcess`, `FollowDistMeters` | ответ получен: поводка как поля нет |
| `Leash A/B` целиком (`LeashAbSet/Tick/Status`, `ResolveCmcFollow`) | багованый rollback, гипотеза отвергнута |
| `GuardianPenaltyAudit`, `InclNameById` | ответ в SOURCE_OF_TRUTH §3.5 |
| `TargetSelectionAudit` | ответ: цель = тело врага |
| `TargetSelCandidate`, `g_targetSel`, `PartyAddTargetSelCandidate` | после удаления аудита остались записи без единого читателя |
| ключи `leashAb`, `leashAbDesired` в ini | вместе с фичей |

`GuardianIntentHunt` оставлен (техдолг: ждём поимки code 4/66), но переехал
в devtools-панель — из продуктового UI он убран.

## 5. Что проверить на первом запуске Build 69

Порядок — по убыванию риска. Первые три пункта важнее остальных вместе взятых.

### 5.1 ГЛАВНЫЙ РИСК: код, который у игрока раньше не выполнялся

До Build 69 при `[devtools] enabled = off` **не работало ничего**: ни тик,
ни поиск тел, ни профили. Теперь всё это работает. Значит, конфигурация
«devtools выключен» впервые в истории проекта исполняет discovery-код.

Что смотреть:
- загрузка сейва **прямо в бой** (не в спокойной локации);
- быстрое перемещение и переходы Гранзис ↔ Bitterblack Isle;
- выход в главное меню и загрузка другого сейва (путь `world unload`:
  раньше он при `off` не проходил вовсе);
- смерть/воскрешение.

Если что-то падает — почти наверняка здесь. В логе перед крашем ищи
`PartyRecon:` и `WorldScan:`.

### 5.2 Поведение могло измениться само по себе

`ddda_pawn_ai_profiles.ini` теперь создаётся и **применяется** при выключенном
DevTools. Раньше у игрока с `off` профили не грузились вообще. Если в sidecar
активен какой-то профиль, пешка поведёт себя иначе, чем в Build 68 — это
не баг, а следствие починки.

Проверь: с `enabled = off` файл создаётся, в логе есть строка про профиль,
активный профиль — тот, что ты ожидаешь.

### 5.3 Цена, которой раньше не было

`WorldScan_Tick` при `off` теперь обходит список актёров каждые 150 мс.
Для игрока это новая нагрузка. Мерить в тяжёлом месте: лагерь с шестью
uEm8000 плюс гоблины, ночной лес, толпа в Грандсисе.

Если FPS проседает — это чинится порогом на продуктовой стороне, но сначала
нужен факт, а не ощущение.

### 5.4 Быстрый A/B на главный инвариант

Один и тот же бой дважды, меняя только `[devtools] enabled`:

| Что смотреть | `on` | `off` |
|---|---|---|
| детектор боя (`combat YES/no`) | переключается | **так же** |
| позиции Аризена и пешки в панели | резолвятся | **так же** |
| роль Guardian и зона телохранителя | работает | **так же** |
| Guardian-фикс (code 54) | applied/vanilla по зоне | **так же** |
| панель DevTools и строка Intent hunt | видны | скрыты |
| JSON/CSV дампы при `researchDump = on` | пишутся | не пишутся |

Расхождение в первых четырёх строках = рефакторинг что-то потерял.

### 5.5 Мелочи, которые легко проглядеть

1. Первая строка лога: `build 69.0-layer-split`. Если другая — тестируется
   старая DLL.
2. Строка `Runtime: image base 0x... exec sections N` должна идти **раньше**
   любых строк DevTools.
3. При `off` в логе: `DevTools: disabled (продукт работает независимо)`.
4. Горячая клавиша `-` (переключение профиля) теперь работает и при `off` —
   раньше не работала. Не нажми случайно.
5. `=` (снимок партии) при `on` + `researchDump = on` должен по-прежнему
   писать `ddda_party_recon_*.json` — это проверка того, что research-хуки
   зарегистрировались.
6. Camera Plus (`F4`) и ползунок party cam берут позиции из `Runtime::` —
   убедись, что камера так же следует за Аризеном и пешкой.
7. При выходе из игры в логе должен быть откат правил
   (`PartyPriorityProfileRestoreAll: DLL detach`) — теперь его делает
   `Runtime::Shutdown()`, а не DevTools.

### 5.6 Чего больше нет (не ищи в панели)

Кнопки `Audit all inclinations`, `Audit target selection`,
`Probe follow distance`, галка `Leash A/B` удалены вместе с кодом.
Строка `Intent hunt` жива, но переехала в панель DevTools.
Ключи `leashAb` и `leashAbDesired` из ini убраны — если твой локальный ini
