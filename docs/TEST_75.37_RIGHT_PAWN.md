# Замер 75.37 — та же драка, но с правильной пешкой

Билд: `builds/47-right-pawn-20260820.zip`, тег **75.37-right-pawn**.

Прошлый бой был отличный, но гистограмма пришла **с чужого тела**: мерили
кастера (`WpnWandAtk 3853 кадра`, `Medicant 660`), а не твою Страйдершу.
Разбор партии промахнулся. Твоей вины тут нет — нажимал ты всё правильно.

Теперь прибор сверяет тело по отпечатку склонностей, сам находит нужное и
пишет об этом в лог. Если не найдёт — гистограмма скажет
`*** WRONG PAWN - DISCARD THIS RUN ***` первой строкой, и ты сразу поймёшь,
что бой не засчитан, а не узнаешь об этом от меня через час.

**Эррата в прошлом логе отработала идеально: одна запись, ноль
восстановлений, держалась весь сеанс.** К ней вопросов нет.

---

## Порядок

1. F12 → `Guardian Doctrine`: `Guardian fix` снята, `inclination lever` снят,
   **`Guardian dagger ban - LIFT IT` стоит**, ползунок **0**, состояние
   `APPLIED`.
2. DevTools → `GOAP probe` → нажать **`Party roster`**, затем
   `probe target` = **own pawn**, затем **`Goal codes`**.
3. Ввязаться в бой.
4. **Уже в бою** включить **`code watch`**.
5. Драться. Нужно 500+ боевых кадров — в прошлый раз ты набрал 4543, так что
   это немного.
6. Выключить **`code watch`** → гистограмма печатается сама.
7. Прислать лог.

## Как понять прямо в логе, что бой засчитан

Ищи в шапке гистограммы:

```
inclinations (RECORD): primary Guardian 1000 ...
inclinations (BODY)  : primary Guardian 1000 ...
```

Обе строки должны говорить **Guardian**. Если появилась строка
`probe target CORRECTED` — прибор сам нашёл нужное тело, всё в порядке.

## Что должно получиться

```
   54  WpnDaggerAtk    <frames>   <in combat>   <entries>
```

Эталон для сравнения — лог 17a: **500 боевых кадров, 0 кинжалов.**
