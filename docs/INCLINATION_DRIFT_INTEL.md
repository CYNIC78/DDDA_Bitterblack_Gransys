**Источник:** отчёт «младшего научного сотрудника» (Gemini), собран из комьюнити

## Что совпадает с нашим runtime (усиливает доверие)

- [✅] Веса 0–1000, девять типов = наше поле `+0x1B90 + id*0x0C`.
- [✅] Primary/Secondary/Tertiary = наши ранги `2/1/0` в checks.

## Модель дрифта (по отчёту)

1. **Кулдаун на боевые действия** (убийства, умения): раз в ~минуты. Долгий бой
   дрифтует сильнее быстрой зачистки.
2. **Без кулдауна (мгновенные, каждый повтор):**
   - D-Pad команды: Go вне боя → Pioneer; Go в бою → Scather;
     Come/Help вне боя → Guardian; Come в бою → Medicant.
   - Лут в бою → Acquisitor (20 предметов = топ).
   - Низкое HP/частые прерывания заклинаний → Medicant.
   - Смерти наёмных пешек → Nexus.
3. **Эликсиры** (Джонатан, за RC): Neutralizing = сброс всех к 500; обычный =
   +100 к одной, -25 ко всем остальным (floor 500). → НАМЁК на пере-нормализацию
   массива, а не аддитивный дрифт (важно для нас!).
4. **Метод 3-5-7-9**: искусственный разрыв весов (1000/900/500) как буфер против
   дрифта на 10–20 часов.
5. **Knowledge Chair** (таверны/лагеря): меняет местами secondary/tertiary, если
   веса близки.

## Что это значит для нашего мода

- Наш лерп (150 мс) на порядок быстрее кулдаунного боевого дрифта — съедаем всплески за 3–6 с.
- **Угроза = безкулдаунные события** (Help-спам → Guardian, лут → Acquisitor):
  они бьют часто и мгновенно.
- Открытый вопрос (A) аддитив vs (B) нормализация. Эликсирная «-25 ко всем»
  намекает на (B) — тогда лерп в одно поле может проигрывать массиву.

## Тест «кто автор» (дешёвый, без реверса)

presetsEnabled=on, Guardian ползунок=300 → в бою спамить Help 10 раз →
смотреть live: дёргается ли каждый клик, и возвращается ли полностью к 300
(аддитив, мы выигрываем) или зависает выше (нормализация/очки — копать глубже).

## Подтверждено runtime-замерами (18.08.2026, наш тест)

Контртест «кто автор» (presetsEnabled on/off) закрыл вопрос:

- **Дрифт АДДИТИВНЫЙ.** Скрытых «очков»/пере-нормализации НЕТ. Игра пишет
  фиксированный кусок в одно поле `+0x1B90 + id*0x0C`, с кулдауном.
- **Вне боя:** только `Go → Pioneer +20` (за кулдаун). `Come/Help` (F2/F3) вне
  боя НИЧЕГО не меняют (вопреки отчёту Gemini — его «Come/Help вне боя → Guardian»
  НЕ подтвердилось).
- **presetsEnabled=off** → Pioneer КОПИТСЯ (+20 → +40 → ...), не возвращается.
  Значит возврат к ползунку — это НАШ лерп, и только он.
- **presetsEnabled=on** → всплеск +15-20, затем лерп гасит за пару секунд.
  Значение «плавает туда-сюда» вокруг ползунка, но НЕ дрейфует.

**Вывод: наша мягкая система ЭФФЕКТИВНО нейтрализует дрифт движка** — не
замораживая, а удерживая характер около ползунка. Дыра, которой мы опасались,
закрыта. Осталось уточнить масштаб боевого Help/Come-дрифта (по отчёту — только
в бою), но механизм тот же (аддитив + кулдаун + наш лерп).

### Замкнутый эксперимент (подтверждает обратимость, 18.08)

```
off → спам F1 → Pioneer копится до ~540 (дрифт накапливается)
on  → за 3-4 с плавно возвращается к 500 (наш лерп стягивает к ползунку)
```

Полный цикл «нанесли дрифт → включили систему → вернула к желаемому».
Доказывает: ползунок = желаемый характер (правда игрока), лерп = мягкая
гравитация (НЕ заморозка), система обратима и не оставляет застывших состояний.
