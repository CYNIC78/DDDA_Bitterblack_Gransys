# 75.46 — твой ini больше никто не тронет

Билд: `builds/56-your-ini-is-yours-20260820.zip`,
тег **75.46-your-ini-is-yours**.

## Причина боли найдена, и это был не ты

В инструкции по сборке (`docs/BUILD_INSTRUCTIONS_RU.md`) в Post-Build Event
стояла вторая строка:

```
xcopy /y /d "$(ProjectDir)ddda_ai_overhaul.ini" "...\DDDA\"
```

**Она затирала твой ini при КАЖДОЙ сборке.** Не при обновлении, не когда ты
что-то копировал — при каждом нажатии «Собрать». Отсюда и «каждый новый тест
выставлять настройки заново».

## Что сделано

**1. Ini больше не едет со сборкой.** Файл в репозитории переименован в
`ddda_ai_overhaul.default.ini` — это справочник со всеми ключами и
комментариями. Он называется иначе и физически не может ничего затереть.

**2. Мод сам дописывает недостающие ключи.** При запуске каждый ключ,
которого нет в твоём файле, дописывается с умолчанием — с отметкой в логе:

```
Config: added missing key [errata] nexusMagicBan = off (new option, default written)
```

Уже выставленные значения не трогаются никогда. Новая опция в новой версии
появится в файле сама.

**3. Свежая установка.** Если ini нет вообще, мод создаёт его с шапкой и
наполняет умолчаниями сам.

## Что нужно сделать ОДИН раз

Открой свойства проекта в Visual Studio → **Build Events → Post-Build Event**
и **удали строку с `ddda_ai_overhaul.ini`**. Оставь только копирование DLL:

```
xcopy /y /d "$(TargetPath)" "C:\Program Files (x86)\Steam\steamapps\common\DDDA\"
```

Пока эта строка там, она будет возить справочник... точнее, уже не будет:
файла с таким именем в проекте больше нет, так что шаг просто начнёт
ругаться «file not found». Лучше удалить.

## Твой нынешний ini

Я сверил присланный файл со справочником: **91 ключ у тебя, 93 в справочнике,
расхождений в значениях нет.** Не хватает ровно двух новых:

```
[errata]
nexusMagicBan = off
nexusMagicValue = 0
```

Их мод допишет сам при первом запуске. **Ничего копировать и выставлять
заново не надо.**
