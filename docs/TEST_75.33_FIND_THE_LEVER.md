# Замер 75.33 — найти рычаг

Билд: `builds/43-find-the-lever-20260820.zip`, тег **75.33-find-the-lever**.

**Билд 42 не собирай — он устарел, эта версия его заменяет.**

Лог 16a показал вещь важнее самой развёртки: при смене склонности на
Guardian раскладка вёдер **не изменилась ни на одну строку**. Разбор —
`docs/GUARDIAN_REPORTS_MAP.md` §19. Теперь прибор проверяет это сам и
называет виновника вслух.

---

## Подготовка

1. Собрать Release|Win32, положить DLL в игру.
2. Пешка — **своя, Страйдер, с кинжалами в руках**.
3. Склонность — **оставь Guardian**, как выставил. Так интереснее всего.
4. Загрузиться, дождаться, чтобы пешка была в партии.

## Порядок нажатий

1. **F12** → панель мода.
2. `Pawn AI Overhaul` → **снять галку `Guardian fix`**.
3. `DevTools - Type Atlas` → `GOAP probe (pawn dash track)`.
4. `probe target` = **own pawn**.
5. Нажать **`Goal codes`** — один раз, чтобы прочиталась таблица имён.
   *(В прошлый раз она не успела, и карта была вся в «slot empty».)*
6. Нажать **`Bucket map`** — снимок «до».
7. Нажать **`Bucket sweep (code 54)`**.
8. **Идти драться.** Пульс каждые 10 секунд.
9. Отчёт печатается сам. Надоело — нажать кнопку ещё раз.
10. **`Bucket map`** ещё раз.
11. Прислать лог.

## Три исхода, и все три — результат

| что напишет лог | что это значит |
|---|---|
| ступени идут, слоты меняются | развёртка работает, получим кривую «ведро → доля ближнего боя» |
| `rule[k] does NOT move the row`, потом другой кандидат | нашли, какое правило реально рычаг |
| `sweep STOPPED - none of the code 54 rules moves the row. THIS IS THE FINDING` | раскладка сейчас вообще не пересчитывается — это и есть ответ, дальше копаем, что её запускает |

Ещё одна строка, которую стоит поискать глазами:

```
layout check: active rules sum +2, so the row SHOULD sit at slot 46;
it actually sits at 46  - consistent
```

или

```
... *** MISMATCH: the bucket layout was NOT recomputed from the current
inclinations (stale layout) ***
```

Вторая — подтверждение находки из лога 16a на новом заходе.

## Что не делать

- Не трогать галку `Guardian fix` во время развёртки.
- Не менять склонности во время развёртки.
- Не менять `probe target` во время развёртки.
- Кинжалы должны быть в руках.
