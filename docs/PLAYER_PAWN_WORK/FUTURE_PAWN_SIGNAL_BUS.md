# Отложенный модуль: боевые реплики пешек → CombatBus

**Статус:** зафиксировано на дальнюю перспективу; не входит в Build 40.

Боевые реплики пешек можно использовать как дополнительный событийный канал. Пример: реплика «он сбит с ног — атакуйте» означает, что движок уже классифицировал состояние противника и передал его pawn message-системе.

Предварительные TypeAtlas-якоря:

- `cCmcMessage`;
- `rCmcMsgConfig`;
- `cCMCMessageResSet`;
- `uGUICmcMessage`;
- `uGUICmcMessage::cLogData`.

Планируемый конвейер:

```text
engine/pawn message event
  -> нормализованный PawnSignal
  -> CombatBus
  -> CombatIntel подтверждает/обогащает состояние боя
```

Возможные сигналы:

- враг сбит с ног;
- открыта уязвимая часть;
- обнаружена стихийная слабость;
- союзник схвачен/без сознания;
- требуется лечение/снятие статуса;
- начата или завершена опасная атака.

Реплика не должна быть единственным источником истины: она может запаздывать, не проиграться из-за cooldown или отсутствовать у конкретного voice set. Поэтому это event enrichment для CombatBus, а не замена живому FSM/HP/status.
