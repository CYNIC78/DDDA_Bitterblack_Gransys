# ============================================================
# ⚠️ ВАЖНО: правильная команда ARCtool
# ============================================================
# arctool -xfs -dd -texRE6 -alwayscomp -pc -txt -v 7
# Флаг -txt ОБЯЗАТЕЛЕН — сохраняет порядок файлов и manifest.
# Использовать свежий ARCtool: старый XFS-конвертер ломал AI/PrioThink/cmc.prt.
# Для исследования только распаковать КОПИЮ; ничего не ставить обратно в игру.

# ════════════════════════════════════════════════════════════
# ЧТО ЭТО ЗНАЧИТ ДЛЯ НАС:
# AIPlActParam ВЕРОЯТНО СОДЕРЖИТ:
#   - Приоритеты выбора действия (атака vs защита vs бафф)
#   - Дистанции для каждого действия
#   - Веса (насколько вероятно пешка выберет это действие)
#   - Условия (при каком HP%, при каком статусе врага)
# 
# РЕДАКТИРУЕМ через ARCtool -xfs → получаем .xml → меняем → пакуем обратно!
# ════════════════════════════════════════════════════════════
