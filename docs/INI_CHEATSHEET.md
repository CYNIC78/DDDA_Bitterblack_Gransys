# Два ини за тридцать секунд

Страница на один экран: **какой файл что делает и когда подействует.** Заводится
потому, что файлов два и у них РАЗНОЕ правило.

## Правило

* **`ddda_entities.ini` — ЖИВОЙ.** Читается при запуске и **перечитывается на ходу**:
  сторож проверяет время изменения файла два раза в секунду, а после правки ждёт
  полсекунды, чтобы не поймать недописанный файл. Сохранил — подействовало.
* **`ddda_ai_overhaul.ini` — НА ПЕРЕЗАПУСК**, кроме одной секции: **`[ranks]` с 85.56 читается
  на ходу** (свой сторож, та же схема и та же защита от недописанного файла). Правка весов действует
  на тех, кто появится ПОСЛЕ неё; уже выданные ступени не меняются — монстр доживает бой со своей.

Уточнения, которые стоит помнить:

* Мод **сам дописывает** отсутствующие ключи в главный ини (`ddda_ai_overhaul.ini`).
  Именно так в 85.52 волкам прилетел `rankScale = on`, и волки выросли.
* В `ddda_entities.ini` автодописывание **специально выключено** — чтобы записанное
  по умолчанию значение не перебивало `[default]`.
* В `ddda_entities.ini` часть ключей читается, но пока не применяется (что именно —
  написано в самом файле в комментариях).

## Что где лежит

| Что хочу поменять | Файл и ключ | Подействует |
|---|---|---|
| Урон всех монстров (в целом сильнее/слабее) | `ddda_entities.ini` `[default] attackMult` | сразу |
| Как монстры держат удар | `ddda_entities.ini` `[default] defenseMult` | сразу |
| Магия монстров | `ddda_entities.ini` `magickAttackMult` / `magickDefenseMult` | сразу |
| Зрение, слух, поводок, скорость | `ddda_entities.ini` `sightRadius` / `hearRadius` / `leashScale` / `speed*` | сразу |
| Размер и разброс вида | `ddda_entities.ini` `scaleMin/scaleMax/scaleJitter` | сразу |
| Разброс особей по рангам (веса, полосы размера, множители урона) | `ddda_ai_overhaul.ini` `[ranks]` | **сразу** (85.56), для новых особей |
| Крепость к эффектам (яд, огонь, стан) по рангам | `ddda_ai_overhaul.ini` `[ranks]` `rankNResist` / `rankNStand` | перезапуск |
| Разрешён ли вид под рангами, трогаем ли размер | `ddda_ai_overhaul.ini` `[species.<вид>]` | перезапуск |
| Темп, ярость, поведение вида | `ddda_ai_overhaul.ini` `[species.<вид>]`, `[monsterTempo]`, `[monsterAI]`, `[aggro]` | перезапуск |
| Горячие клавиши, панель | `ddda_ai_overhaul.ini` `[hotkeys]`, `[inGameUI]` | перезапуск |

## Два контракта, которые не обсуждаются

1. Владелец кладёт в игру **только `dinput8.dll`**. Если для фичи нужен ключ —
   это говорится вслух: файл, секция, строка, и что будет без неё.
2. **Здоровье монстров не трогаем никогда.** Запасы по эффектам (яд, огонь, стан) —
   можно, это другая величина.

## Как это выглядит в логе

| Что проверить | Строка |
|---|---|
| какие числа взяты | `EnemyTuner: CombatStats x3.00/3.00/1.00/1.00 ...` |
| какая ступень выдана телу | `EnemyTuner: rank uEm0100 veteran(2) size 1.117 atk x1.20 -> 0x10D57470` |
| какие веса задуманы на сессию | `Monster Director: ranks uEm0100 ON  novice w0.34 ...` |
| сработала ли крепость | `EnemyTuner: resist applied uEm0100 ... readback pois 2000 froz 1600 burn 600` |
| перечитались ли веса на ходу | `Monster Director: ranks RELOADED from ini (live read, 85.56)` |
