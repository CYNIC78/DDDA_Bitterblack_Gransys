## Текущий milestone

**Build 84.64** — `tactical-dpad-commands`. Тактическая система приказов D-Pad («Ко мне!» / «Вперед!» / «Помогите!») с плавным затуханием (6с decay) и пином целей:
- `Tactical Command Engine`: мгновенный отклик (0мс) — приказ «Вперед!» пинит цель в фокусе камеры штурмовикам с рывком x1.25; «Ко мне!» стягивает отставших пешек на спринте к Аризену.
- `Cognitive Impulse with Smooth Decay`: ситуативный импульс инклинаций (+300 Scather, +350 Guardian, +300 Medicant) с плавным затуханием за 6 секунд без порчи сохранений.
- `Complete Save Protection`: устранение ванильного дрифта склонностей в `DDDA.sav`.

**Build 84.63** — `dpad-order-watch-probe`. Исследовательский зонд OrderWatch для изучения ванильной системы приказов D-pad («Ко мне!» / «Вперед!» / «Помогите!»).

**Build 84.61** — `nexus-doctrine-wingman`. Полноценная доктрина Nexus: выбор напарника-пешки (защита кастов мага / штурмовая двойка) + двухуровневый перехват.

**Build 84.60** — `hobgoblin-flail-tempo-tuner`. Калибровка ярости гоблинов и хобгоблинов + фикс ускорения сабельного раша (`SwMoveAttack`).

**Build 84.58** — `smart-nukes-chimera-safety`. Фикс краша на составных боссах (Химера/uEm5200) + строгий Nuke Gating.

**Build 84.57** — `smart-nukes-proximity-fix`. Строгий радиус боя для разблокировки ядерных спеллов (< 32м) + фильтрация трупов боссов + CasterWatch только для магов.

**Build 84.56** — `caster-tactics-hfb-logger`. Онлайн-трекер Священного Заряженного Выстрела (HFB) и кастов заклинаний пешек.

**Build 84.55** — `pawn-combat-mastery`. Комплексный пакет боевого поведения: Двухуровневый Гвардиан + Спасение Аризена + Умный кастер + DDON Sanctuary.

**Build 84.53** — `smart-nukes-deep-scan`. Глубокий охват планировщика спеллов + строгий запрет ядерных кастов на мелочи:
- `IsLargeEnemyOrBossPresent()`: убрано условие `enemyCount >= 6`, из-за которого Болид разблокировался на стаях хобгоблинов. Блокировка 15с кастов действует на всех обычных мобах.
- Разблокировка nuke-кастов активна строго против боссов (Огры, Циклопы, Химеры, Дрейки, Големы, Даймон).
- `WalkPlanWand()`: сканирование всех 91 слотов планировщика в `cAIGoalPlanning` для 100% покрытия всех спеллов.

**Build 84.52** — `caster-smart-nukes`. Умное контекстное управление спеллами синих пешек + разблокировка дальности Focused Bolt:
- `Smart Nuke Gating`: автоматическая блокировка долгих 15-секундных кастов (Bolide, Maelstrom, Seism, Fulmination) против мелких стай мобов с переключением на быстрые спеллы (Comestion, Ingle, Levin, Frigor).
- Мгновенная разблокировка ядерных спеллов (15 м) против крупных монстров и боссов (Огры, Циклопы, Химеры, Дрейки, Големы, толпа от 6 врагов).
- `Focused Bolt (cCmcWandDXL)`: дальность заряженной атаки посоха расширена с 2 до 15 метров, позволяя пешкам использовать святой заряженный выстрел (Holy Focused Bolt) на дальней дистанции.

- `GuardianDoctrine`: надежный перехват целей телохранителем с двухуровневой зоной.

**Build 84.50** — `rescue-and-guardian`. Синхронная работа проактивного телохранителя + общепартийного спасения:

- `PartyRescueProtocol`: общепартийное спасение Аризена от захватов и нокдаунов (успешно подтверждено на хобгоблинах в логе).
- `DDON Return Sanctuary`: броня и скорость на возврате монстров.

**Build 84.49** — `party-rescue`. Общепартийный протокол экстренного спасения Аризена (Party Emergency Rescue Protocol):
- `PawnAI::Rescue`: автоматическое распознавание захвата/удержания Аризена (огры, гримгоблины, гарпии, циклопы, химеры, драконы).
- Синхронный захват цели (`uCmc + 0x2EB8`) и наведение фокуса для ВСЕХ пешек в партии (Главная + Наёмники).
- Снятие штрафов пассивности и максимальный приоритет атаки (+5) + скоростной рывок (x1.30) для немедленного сбивания захвата с монстра.

**Build 84.48** — `two-tier-guardian`. Двухуровневый защитный периметр телохранителя + фильтрация по намерению врага:
- `Critical Melee Perimeter (4..6м)`: максимальный сигнал перехвата (STRONG SIGNAL) любой цели, подошедшей вплотную к Аризену.
- `Preempt Perimeter (6..12м)`: упреждающий перехват (`PREEMPT-INTERCEPT`) срабатывает ТОЛЬКО если враг нацелен на Аризена (`targetMember == MEMBER_ARISEN`) или выполняет атакующее действие.
- Если враг во внешней зоне фланкирует другую пешку, Гвардиан сохраняет позицию рядом с Аризеном и не дает увести себя в сторону.
- Жесткий поводок (`leashDistance = 14..18м`): запрет удаленных атак при отдалении от Аризена.

**Build 84.47** — `guardian-proactive`. Проактивный перехват целей телохранителем (Guardian Proactive Target Pinning) + жесткий поводок:
- `GuardianDoctrine`: при входе врага в зону вокруг Аризена (8..12м) его адрес пинится в боевой регистр цели пешки (`uCmc + 0x2EB8`) и фокус взгляда (`+0x14E0`).
- Пешка-телохранитель перехватывает приближающегося врага наперерез до нанесения первого удара по Аризену.
- Жесткий поводок (`leashDistance = 14..18м`): пешка прекращает погоню и возвращается к Аризену при отдалении, предотвращая зависание на краю карты.

**Build 84.46** — `ddon-sanctuary`. Броня и ускорение возврата на спавн в стиле Dragon's Dogma Online (DDON Return Sanctuary):

- `MonsterTempo`: автоматический бонус скорости бега домой (`returnSpeed = 1.30x`), предотвращающий зависание мобов на возврате.
- Мгновенное и безопасное восстановление ванильной базы брони и темпа при повторном агре в бой или по прибытии в лагерь.
- Новые ключи в `ddda_entities.ini`: `returnArmor = on`, `returnArmorMult = 4.0`, `returnSpeed = 1.30`, `returnDamageCut = 0.80`.
