  1. **HFB (holy focused bolt)** — [ДОКАЗАНО наблюдением] приём есть у пешки, но вес

     пересчитает). Низкая сложность.

     а не слепо поднимать вес. Высокая сложность.
  3. Знание↔элемент (огонь против дрейка со звёздами) — проверить связку бестиария.
  4. Каст-тайм↔толпа (долгий каст по мёртвой толпе) — проверить скоринг скорости.
- **Skill-selection слой** — новый вертикальный срез (разведка весов КОНКРЕТНЫХ
  скиллов, не priority). Один вход на все скилл-комбо:

## План рефакторинга (после A/B поводка)

**См. `docs/REFACTOR_TASK.md`** — полное задание на следующую сессию (шаги,
Definition of Done, судьба проб). Кратко: вынести runtime/ (WorldScan, PartyRecon,
PriorityPlatform) из-под devtools-флага, вычистить отжившие пробы, продукт должен
работать при `[devtools] enabled = off`.

Итог поводка (закрыт): рантайм-поля «длины поводка» НЕТ (доказано на 4 слоях),
рычаг = веса склонностей. Guardian vocation-матрица — см. `GUARDIAN_VOCATION_MATRIX.md`.

**Проблема:** `DevTools.cpp` (6k+ строк) смешал три слоя — продуктовый runtime,
исследовательские пробы, собственно DevTools. Плюс **критический баг**: продукт
(детектор боя, доктрина, позиции) зависит от `WorldScan_Tick`, который гейтится
`[devtools] enabled` → выключи DevTools = сломался продукт.

**Цель:**
```text
src/runtime/     — продуктовый, всегда включён:
                  PartyRecon (uPlayer/uCmc, позиции, боевая цель)
                  WorldScan (враги, боевые действия, сигналы детектора)
                  PriorityPlatform (транзакции + GuardianFix)
src/pawnai/      — поведение (уже есть)
src/devtools/    — чисто исследовательское (SCAN/DUMP/HUNT + пробы), гейтится
```

**Правила (из опыта):**
1. Проба = временный инструмент: «вопрос → ответ → SOURCE_OF_TRUTH → удалить».
2. Продукт НЕ зависит от research-флага.
3. Полный census в бою — ЗАПРЕЩЁН (краши); точечные пробы — только по якорям.

**Судьба проб-кнопок:**
- Audit Guardian penalties → удалить (ответ в §3.5);
- Probe follow distance → удалить после A/B поводка (ответ в §5.1);

## Неподвижные принципы (напоминание)

- Не хранить heap-указатели; не менять `DDDA.sav`; не угадывать offsets.
- validate → write → readback → convergence → rollback.
- Приоритет-слой — «совет», а не приказ; GOAP/FSM исполняют сами.
- F9 не трогать (сохранение пользователя).
