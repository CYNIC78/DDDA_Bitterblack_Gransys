## ШАГ 0: Что делать со старым динпут-модом?

Старый `dinput8.dll` и наш новый `dinput8.dll` — это РАЗНЫЕ моды,
но файл называется одинаково. Две DLL с одним именем не могут быть
в папке одновременно.

### Вариант А (рекомендую для тестов):
1. Зайди в папку с игрой (где `DDDA.exe`)
2. Найди `dinput8.dll` (старый мод)
3. ПЕРЕИМЕНУЙ его в `dinput8_OLD.dll`
4. Наш новый `dinput8.dll` положи туда же
5. В нашем `ddda_ai_overhaul.ini` пропиши:
   ```
   loadLibrary = dinput8_OLD.dll
   ```
   → старый мод будет загружен как дополнительная библиотека,
   а наш будет главным.

### Вариант Б (если читы не нужны для теста):
1. Просто удали/переименуй старый `dinput8.dll`
2. Наш `dinput8.dll` будет единственным — всё будет работать.

## ШАГ 1: Что у тебя должно быть установлено

Проверь:
- [ ] Visual Studio (2017, 2019 или 2022 — любая версия)
  - Бесплатная Community Edition подойдёт
  - При установке ВАЖНО выбрать галочку:
    **«Разработка классических приложений на C++»**
- [ ] DirectX SDK (June 2010)
  - Если нет — не страшно! Современный VS включает Windows SDK
    с поддержкой DirectX. Может заработать без него.

---

## ШАГ 2: Открой папку backup_all_files

1. Скопируй папку `backup_all_files` из проекта куда-нибудь
   на компьютере, например: `C:\Projects\ddda-ai-overhaul\`

2. Внутри должно быть так:
   ```
   C:\Projects\ddda-ai-overhaul\
   ├── ddda-ai-overhaul.vcxproj    ← проект VS
   ├── dinput8.def
   ├── ddda_ai_overhaul.ini        ← конфиг
   ├── dinput8.h
   ├── stdafx.cpp, stdafx.h
   ├── d3d9.cpp, d3d9.h
   ├── InGameUI.cpp, InGameUI.h
   ├── iniConfig.cpp, iniConfig.h
   ├── Hotkeys.cpp, Hotkeys.h
   ├── steam_api.h, resource.h
   ├── MinHook\   (папка)
   ├── ImGui\     (папка)
   └── src\       (папка с нашими модулями)
       ├── dinput8.cpp
       ├── PawnAI.cpp, PawnAI.h
       ├── EnemyAI.cpp, EnemyAI.h
       ├── CombatIntel.cpp, CombatIntel.h
       └── Nightmare.cpp, Nightmare.h
   ```

## ШАГ 3: Открой проект в Visual Studio

1. Запусти Visual Studio
2. **File → Open → Project/Solution**
3. Выбери файл `ddda-ai-overhaul.vcxproj`

Если VS спросит про **Retarget Projects** (перенацеливание) —
нажми **OK**. Это нормально, VS подстроит проект под твою версию.

---

## ШАГ 4: Настройка (если нужно)

### 4a. Выбор конфигурации
Вверху экрана, в выпадающих списках выбери:
- **Release** (не Debug!)
- **Win32** (не x64!)

```
[ Release ▼ ]  [ Win32 ▼ ]
```

### 4b. Если VS ругается на DirectX SDK
Если при сборке ошибка: «Cannot open include file: d3dx9.h»:
1. Правой кнопкой по проекту → **Properties**
2. **VC++ Directories → Include Directories**
3. Удали строчку `$(DXSDK_DIR)Include` (если SDK не установлен)
4. Будем надеяться что Windows SDK подхватит. 
5. Если всё равно ошибка — скачай DirectX SDK (June 2010) с Microsoft.

---

## ШАГ 5: Сборка!

1. Нажми **Build → Build Solution** (или Ctrl+Shift+B)
2. Жди. Внизу (Output window) появится лог компиляции.

### Если всё хорошо — увидишь:
```
========== Build: 1 succeeded, 0 failed ==========
```

И в папке `Release\` появится файл **`dinput8.dll`** !

### Если ошибки:
Скопируй текст ошибок из Output window и пришли мне.
Я помогу исправить.

---

## ШАГ 6: Установка и тест

1. Скопируй ДВА файла в папку с игрой:
   ```
   Release\dinput8.dll          →  DDDA\
   ddda_ai_overhaul.ini         →  DDDA\
   ```

2. Убедись что старый `dinput8.dll` переименован (см. Шаг 0)

3. Запусти игру

4. Нажми **F12** — должно появиться меню с вкладками:
   - **Pawn AI Overhaul v2.0**
   - **Combat Intel**
   - **Enemy AI Overhaul**
   - **Nightmare: Bitterblack Gransys**

## ШАГ 7: Быстрая проверка что всё работает

### Проверка 1 — инклинации:
- F12 → Pawn AI Overhaul → раскрой «Live Inclinations»
- Должны показаться реальные значения инклинаций твоей пешки
- Если видишь числа — оффсеты правильные!

### Проверка 2 — Combat Intel:
- F12 → Combat Intel → включи галку
- Ударь любого врага → в «Damage Ring Buffer» должна появиться запись
- Должен показать group=XX

### Проверка 3 — санитарный кордон:
- Посмотри на значения Guardian/Nexus/Acquisitor
- Они должны быть НИЖЕ чем 3-я полезная инклинация
- (Cap считается автоматически, видно в UI)

## ⚡ Быстрые ответы на частые вопросы

**Q: Нужно удалять старый dinput8?**
A: Переименуй в `dinput8_OLD.dll` и пропиши в нашем .ini:
   `loadLibrary = dinput8_OLD.dll`

**Q: А если у меня Steam версия, а не GoG?**
A: Оффсеты pBase и структура данных одинаковые!
   Сигнатуры тоже одинаковые. Должно работать.

**Q: А если у меня нет DirectX SDK?**
A: Попробуй собрать без него — часто работает через Windows SDK.
   Если ошибка — скачай June 2010 SDK с сайта Microsoft (бесплатно).

**Q: А какие именно галочки нужны при установке VS?**
A: Только «Разработка классических приложений на C++».
   Всё остальное опционально.
